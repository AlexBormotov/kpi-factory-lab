# Словарь станка

Коротко: что значит термин **в этом репозитории**. Полный метод — файлы в `ai-factory-kit/`, сюда их не копируем.

## Два списка, которые путают

**11 столпов** — шкала «насколько репо готов к агенту» (`ai-factory-kit/04-readiness-model.md`). Считаются на шаге аудита, не внутри калькулятора.

**12 md файлов** (`01` … `12`) — главы метода. Это справочник. Калькулятор их не импортирует. Позже отдельный requirement: упражнение на каждый файл.

## Loop, harness, factory

**Loop** — круг: взять задачу → изменить калькулятор → прогнать pytest → снова. Единица: одно изменение.

**Harness** — стены вокруг круга: skills в `.cursor/skills`, узкий список файлов, которые можно менять, команда «готово» = pytest.

**Factory** — много таких кругов на одном trunk, с воротами. У нас пока один учебный loop, не поток в прод.

## Оракул и улики

**Оракул** — проверка «сделано правильно»: `tests/test_kpi.py` против вашего `expected/kpi.csv`. Не чат и не дашборд.

**Фикстура** — замороженный вход. Здесь: `fixtures/clicks.csv` и `fixtures/conversions.csv`.

**Эталон** — ваш файл `expected/kpi.csv`. Судья. Агент его не заполняет.

**Edit surface** — что агенту можно менять после первого `generate.py`: только `kpi/calculator.py`.

**Класс изменений** — один тип задачи, про который можно решать ворота. Сейчас: «починить калькулятор, не трогая эталон и фикстуры».

**G6 / улики** — пакет, который можно прочитать без чата: таблица KPI, отчёт pytest, SHA **файла** `kpi/calculator.py` (не git-коммит). Дашборд их **показывает**. Он не судья. Если SHA в отчёте не совпал с кодом — «улики устарели».

**Negative control** (позже): нарочно сломать фильтр ботов — должен покраснеть тест Cost, не «вообще всё».
