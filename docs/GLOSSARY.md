# Словарь станка

Коротко: что значит термин **в этом репозитории**. Полный метод — файлы в `ai-factory-kit/`.

## Столпы — это не «калькулятор сломан»

**11 столпов** отвечают на вопрос: *можно ли агенту самому класть код в общую ветку?*
Они **не** отвечают: *правильно ли считаются Cost и Revenue?*

Pytest зелёный — числа сходятся с эталоном. Это качество **формулы**.
Pre-Functional на аудите — «нет робота на входе в общую ветку». Это готовность **цеха**, не «продукт врал».

Онлайн-банк в прод не пускают без столпов. Этот станок — лаборатория. Его «прод» — папка на диске. Столпы не прошли → агенту нельзя **без вас** вливать правки. Калькулятор при этом уже считает.

Поэтому после аудита идут **ворота**: таблица «можно / нельзя без человека». Ответ «нельзя» — нормальный исход, не провал продукта.

## Trunk, ветка, CI

**Trunk** — главная общая линия истории. У нас это ветка `main`. «Сесть в trunk» = ваш коммит стал новым концом `main`.

**Защита ветки** (branch protection) — настройки на GitHub: «в `main` нельзя попасть, пока робот не сказал ок». Без этого любой `git push` проходит. Локальный pytest на ноутбуке робот не видит.

**CI** — робот, который после пуша сам запускает команды (у нас `python -m pytest`).
**CD** — отдельно: выкладка на сервер. CI можно иметь без CD. Для станка CD не нужен.

## Intent: trailer, run record, граф, сенсор

**Trailer** — хвост в сообщении коммита, служебная строка. Пример: `REQ-001: WU-001`.
Зачем: через год `git log` отвечает «этот коммит делали ради какого требования», не читая чат.

**Run record** — папка прогона `docs/runs/WU-001/`: что запускали, какой код выхода, какой SHA. Другой человек должен повторить команды без этой переписки.

**Граф** — не картинка в Miro. Скрипт, который проверяет: у коммита есть trailer, у work unit есть REQ, у REQ есть файл. Сломанная ссылка → проверка красная. У нас этого скрипта нет. Пока связь «глазами»: WU-001 ссылается на REQ-001.

**Сенсор** — программа, которая ловит расхождение «в ARCH написано одно, в коде другое». Без калибровки её нельзя ставить в гейт. Сейчас не делаем.

## Loop и оракул

**Loop** — агент меняет калькулятор, гоняет pytest, повторяет.

**Оракул** — pytest против `expected/kpi.csv`.

**Edit surface** — дальше агенту можно менять только `kpi/calculator.py`.

**Класс изменений** — один тип задачи для ворот: «починить калькулятор, не трогая эталон».
