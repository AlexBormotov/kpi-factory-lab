## Исход

После работы есть сырые CSV, калькулятор считает таблицу `campaign × day`, человек заполняет эталон, pytest говорит да/нет, HTML показывает те же числа и последний отчёт тестов.

## Критерии приёмки

Копировать в work unit **дословно**, с этими id.

1. **AC-1.** Команда `python generate.py` создаёт `fixtures/clicks.csv` и `fixtures/conversions.csv`. Объём не больше: 3 кампании, 3 дня, 30 кликов, 15 конверсий.
2. **AC-2.** В сырье есть разнообразие: хотя бы один клик с `is_bot=true`, одна конверсия с `type` не `purchase`, один день только с кликами, один день с покупкой без валидных кликов.
3. **AC-3.** Тот же запуск пишет шаблон `expected/kpi.csv`: все пары `campaign,day` из сырья, колонки `cost` и `revenue` пустые. Числа эталона пишет только человек.
4. **AC-4.** Калькулятор считает: Cost = сумма `cost` кликов с `is_bot=false`; Revenue = сумма `payout` где `type == purchase`; группировка `campaign × day`; Profit = Revenue − Cost; ROI = Profit / Cost если Cost > 0, иначе пусто.
5. **AC-5.** Pytest сравнивает Cost и Revenue с `expected/kpi.csv`. Profit и ROI тесты считают сами по формулам AC-4. Пока эталон пустой, сюита падает с понятной ошибкой «заполните эталон», а не с зелёным прогоном.
6. **AC-6.** `python -m kpi.report` пишет `output/dashboard.html`. Страница показывает таблицу KPI и таблицу последнего pytest (сколько прошло/упало, SHA). Если SHA в отчёте ≠ текущий код — текст «улики устарели». Страница не считает KPI заново и не запускает pytest.
7. **AC-7.** В репозитории есть `docs/GLOSSARY.md`: термины фабрики на этом станке (оракул, фикстура, класс изменений, harness, loop, G6, edit surface, столпы vs файлы `01`–`12`).
8. **AC-8.** В README или GLOSSARY явно сказано: после первого прогона генератора агент в следующих циклах меняет только `kpi/calculator.py`. Генератор, фикстуры, эталон, тесты и report — заморожены.

## Вне скоупа

- Связь с любым другим продакшен-дашбордом или BigQuery.
- Генератор в Docker / пакет раз в минуту.
- LLM как автор эталона или как оракул (`claude-thinking` не пишет `kpi.csv`).
- Веб-сервер, фильтры, графики.
- CI, защита ветки, unattended landing (это шаг аудита и девяти ворот, не этот requirement).
- Лаборатория «прогнать каждый из 12 md кита и увидеть его результат на этом репо» — отдельный будущий requirement, не REQ-001.
