# Глава 07 — человек / агент на этом станке

Фабрика ускоряет цикл. Человек не читает каждый diff, если оракул держит формулу. На этом станке человек всё равно нужен в двух местах продукта и в одном месте цеха. Остальное агент уже делает.

| Что | Кто | Почему |
|---|---|---|
| Цифры `cost` / `revenue` в `expected/kpi.csv` | **человек** | Это оракул. Агент, который пишет эталон, проверяет сам себя |
| Новый requirement («что строить») | **человек** | Grill / приём REQ. Агент пишет черновик, не утверждает цель |
| Починить `kpi/calculator.py`, эталон не трогать | **агент** | Pytest говорит да/нет. Это и есть loop |
| `python generate.py` после заполненного эталона | **нельзя никому** | Со трёт шаблон. Человек, если меняет сырьё, заполняет эталон заново |
| Merge PR в `main`, когда CI зелёный | **агент по вашей просьбе** | Ruleset всё равно требует job `test`. Это не unattended landing: вы сказали «вливай» |
| Сесть в `main` без человека навсегда | **нельзя** | G2/G5/G9 открыты. Автономию не выдаём |
| Выкладка клиентам | нет роли | Продукта-сервиса нет (G8 пусто) |

Итог: два человеческих гейта продукта — **эталон** и **цель (REQ)**. Третий, если появится — калибровка эталона заново. Diff калькулятора при зелёном pytest человек может не читать.
