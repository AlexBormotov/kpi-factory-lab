# Глава 09 — свой станок, не платформа

Нужен учебный контур: видно loop, оракул, ворота. Не нужен канал продаж, подпись за дефект в проде и штат «с понедельника».

| Модуль платформы (глава 09 кита) | У нас уже | Покупать? |
|---|---|---|
| Файл требования | `docs/intent/REQ-*.md` | нет |
| Архитектура | `ARCH-001.md` | нет |
| Work unit | `WU-*.md` | нет |
| Оракул + negative control | pytest + `scripts/negative_control.py` | нет |
| CI / защита `main` | GitHub Actions + ruleset `main-g7` | нет (уже хост git) |
| Граф рёбер как проверка | нет скрипта | не покупаем; N/A для лаборатории |
| Судья документов | N/A (глава 06) | нет |
| Подпись за прод | не воспроизводится кодом | не наш вопрос |

Строим markdown + pytest, потому что цель — выучить метод на девяти строках KPI. Покупка intent-платформы добавила бы модули, которых мы сознательно не ставим (граф, сенсор, судья). Четыре вещи из кита, которые «не софт» (подпись, канал, клиенты, штат), этому репо не нужны.

Решение: **свой станок**. Пересмотреть, только если целью станет не учёба, а поставка цеха чужой команде под договором.
