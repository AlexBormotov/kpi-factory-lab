# Глава 11 — это не pytest

`11-coaching-layer.md` про людей и **путь поставки** (заявка → репо → проверка → trunk → потребитель). Не про то, сходится ли Cost.

Шесть инструментов (STATIK и остальные) — для человека, который ведёт внедрение в организации. Их вопросы судит человек. Если поставить их вместо оракула, G4 сломается: «дешёвый частый неподделываемый» станет мнением.

На этом станке процесс коучинга **не внедряем**. Репо один, путь один, потребителя-клиента нет. Файл прочитан, чтобы не спутать коучинг с фабрикой.
