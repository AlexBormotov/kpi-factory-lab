# Девять ворот

Класс задачи, про который спрашиваем: **агент меняет только `kpi/calculator.py`, эталон и фикстуры не трогает, pytest должен остаться зелёным.**

Это не «пускаем в прод». Это девять да/нет. Одно нет — **в `main` без человека нельзя.**

Замерено: SHA `7af8c97`, `python -m pytest -q` → 5 passed. Ветка `main` = trunk.

---

| Ворота | Простыми словами | Вердикт | Почему |
|---|---|---|---|
| **G1** Объём | Задача одна и понятно, когда конец | **да** | Конец: pytest зелёный, тронут только калькулятор |
| **G2** Зрелость | Репо хотя бы L3 (проверки сами стопорят плохой коммит) | **нет** | Аудит: Pre-Functional. Нет линтера-гейта, не было CI |
| **G3** Риск | Не логин, не деньги, не миграция БД, не публичный контракт банка | **да** | Учебный CSV, нет платежей |
| **G4** Оракул | Проверка дешёвая, на каждый раз, её нельзя тихо подделать | **слабо / нет** | Эталон ваш, pytest быстрый. Нет запрета агенту править тесты (только текст в README). Negative control не делали |
| **G5** Harness | Агент в песочнице, есть SHA «от чего отталкивались» | **нет** | Один каталог, без worktree. SHA есть в git, изоляции кандидата нет |
| **G6** Улики | Diff + тесты + лог привязаны к двум SHA (было / стало) | **частично** | Run record есть. Дашборд не в git. Нет пакета «этот SHA ↔ этот pytest» на каждый будущий коммит |
| **G7** Независимый судья | Сервер не примет `main`, пока робот не прогнал **этот** SHA. Хук на ноутбуке не считается | **нет** | Не было CI. Даже после файла workflow: пока GitHub не требует зелёную галку, ref примет что угодно |
| **G8** Выкладка отдельно | Тот, кто пишет в `main`, сам не выкатывает прод | **да (пусто)** | Продакшена нет. Положить в `main` ≠ открыть банк клиентам |
| **G9** Откат | Сломали `main` → стоп, revert на прошлый зелёный SHA, тесты снова | **нет** | Нет правила «красная сюита → линия стоит». Откат руками |

**Итог: без человека в trunk — нет.**  
Держит в первую очередь **G7** (и G2). Лечение: CI + на GitHub включить «require status checks» на `main`.

Потолок размера: истории мало (2 коммита). Свой p75 не считается. Пока любой unattended запрещён и из‑за размера, не только из‑за ворот.
