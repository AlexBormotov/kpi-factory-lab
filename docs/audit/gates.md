# Девять ворот

Класс задачи, про который спрашиваем: **агент меняет только `kpi/calculator.py`, эталон и фикстуры не трогает, pytest должен остаться зелёным.**

Это не «пускаем в прод». Это девять да/нет. Одно нет — **в `main` без человека нельзя.**

Замерено: SHA `7af8c97`, `python -m pytest -q` → 5 passed. Ветка `main` = trunk.

---

| Ворота | Простыми словами | Вердикт | Почему |
|---|---|---|---|
| **G1** Объём | Задача одна и понятно, когда конец | **да** | Конец: pytest зелёный, тронут только калькулятор |
| **G2** Зрелость | Репо хотя бы L3 (проверки сами стопорят плохой коммит) | **нет** | Аудит: Pre-Functional. CI есть, линтера-гейта нет — столп 1 не L3 |
| **G3** Риск | Не логин, не деньги, не миграция БД, не публичный контракт банка | **да** | Учебный CSV, нет платежей |
| **G4** Оракул | Проверка дешёвая, на каждый раз, её нельзя тихо подделать | **да, с оговоркой** | Эталон ваш. `python scripts/negative_control.py`: без фильтра ботов краснеют только Cost-тесты. Агент всё ещё *может* править `tests/` (конвенция, не CODEOWNERS) |
| **G5** Harness | Агент в песочнице, есть SHA «от чего отталкивались» | **нет** | Один каталог, без worktree. SHA есть в git, изоляции кандидата нет |
| **G6** Улики | Diff + тесты + лог привязаны к двум SHA (было / стало) | **частично** | Run record есть. Дашборд не в git. Нет пакета «этот SHA ↔ этот pytest» на каждый будущий коммит |
| **G7** Независимый судья | Сервер не примет `main`, пока робот не прогнал **этот** SHA. Хук на ноутбуке не считается | **да (на GitHub)** | Ruleset `main-g7`: в `main` только через PR, обязательная проверка `test`, без force-push. JSON: `.github/main-g7-ruleset.json` |

| **G8** Выкладка отдельно | Тот, кто пишет в `main`, сам не выкатывает прод | **да (пусто)** | CI — только pytest и negative control. Нет job deploy и нет флага «включить клиентам». Merge PR ≠ прод. Прод как сервис у станка нет |
| **G9** Откат | Сломали `main` → стоп, revert на прошлый зелёный SHA, тесты снова | **нет** | Нет правила «красная сюита → линия стоит». Откат руками |

**Итог: без человека в trunk — нет.**  
G4 закрыт negative control в CI. G7 на GitHub закрыт. G8 закрыт пусто: merge не выкатывает продукт. Дальше держат G2 (не L3), G5, G9.

Потолок размера: истории мало. Свой p75 не считается.
